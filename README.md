# Water Meter Analysis and Billing Management Platform

A full-stack subscriber and billing management automation developed for water utilities and local governments, operating with a tiered tariff algorithm.

> **⚠️ Legal Disclaimer:** This project is an independent concept application developed for software portfolio purposes. All subscribers, consumption indices, and billing data in the system are completely mock data generated by a custom data generator algorithm. The application has no affiliation with any real-world official institution, municipality, or water utility.

## 🚀 Core Features

* **Tiered Tariff Engine:** Dynamic unit pricing and realistic bill calculation based on consumption tiers (e.g., 0-15 m³, 15-20 m³, 20+ m³ limits).
* **Automatic Data Generation:** Upon initial startup, the system automatically creates database tables and generates mock subscriber and reading data for testing scenarios.
* **Zero Balance Control:** Custom edge-case handling and UI routing for invoices with zero consumption (0 TL).
* **Dynamic Reporting:** Real-time visualization of subscriber history, index tracking, and accrual reports through a modern user interface.

## 🛠️ Technologies Used

* **Backend:** Java, Spring Boot, Spring Data JPA, REST API
* **Frontend:** React.js, Vite
* **Database:** SQL Server / PostgreSQL
* **Tools:** Maven, Lombok

## ⚙️ Setup and Execution

Follow the steps below to run the project in your local environment. SQL tables and test data will be generated automatically when the application starts; no manual SQL scripts are required.

1. **Database Preparation:** 
   Create an empty SQL database on your local server.
2. **Configuration:**
   Update the database connection credentials (`spring.datasource.url`, `username`, `password`) in the `application.properties` file located in the backend folder to match your local environment.
3. **Starting the Backend:**
   Build and run the Spring Boot application using your IDE or terminal.
4. **Starting the Frontend:**
   ```bash
   cd frontend
   npm install
   npm run dev
